================================================================================
Execution environment: requirements and expected resource use
================================================================================

--------------------------------------------------------------------------------
1. HARDWARE REQUIREMENTS
--------------------------------------------------------------------------------

    RAM         16 GB for claims 1-3, which start the JVM backend with a fixed
                14 GB maximum heap (constraints.txt). Claims 4-9 need under 8 GB
                with 8 worker processes (about 0.7 GB per worker at most).
    Disk        ~60 GB free: the evaluation data once unpacked by loadData.sh
                (~3.4 GB download; the files the figure scripts actually read
                are ~2.1 GB, but the published archives unpack to much more -
                see zenodo/README.md), 600 MB of Bloom filters, ~1 GB Python
                environment, <100 MB of results.
    CPU         Any x86-64 processor. Claims 4-9 use all cores by default
                (-j N to limit); 4+ cores recommended.
    Network     Only during installation (packages, Bloom filters, data).
    GPU         Not used.

Reference platform for our own verification:

    Ubuntu Linux, x86-64, 12 CPUs, 27 GB RAM, OpenJDK 21, CPython 3.13

--------------------------------------------------------------------------------
2. SOFTWARE REQUIREMENTS
--------------------------------------------------------------------------------

    OS          Linux (tested); macOS and Windows untested - use Docker there
    Python      3.11 or 3.12 with the venv module (pinned dependencies,
                ../artifact/requirements-lock.txt)
    Java        JRE 11 or newer, on PATH or via JAVA_HOME (claims 1-3 only)
    Docker      optional alternative to all of the above (../Dockerfile)

../install.sh creates ../.venv and installs everything into it; nothing is
installed system-wide.

--------------------------------------------------------------------------------
3. PUBLIC INFRASTRUCTURE
--------------------------------------------------------------------------------

The artifact runs on public research infrastructure. Any standard node of

    CloudLab     https://www.cloudlab.us/
    Chameleon    https://www.chameleoncloud.org/

comfortably exceeds the requirements; no special allocation or hardware is
needed. Google Colab is NOT suitable for claims 1-3 (constraints.txt); claims
4-9 fit in a Colab runtime. No access to author-controlled machines is needed.

--------------------------------------------------------------------------------
4. EXPECTED RUNTIME (reference platform)
--------------------------------------------------------------------------------

    install.sh                                  10 - 25 min, dominated by the
                                                Bloom filter (~600 MB) and data
                                                downloads

    claims/claim1_install/run.sh                ~2 s     (plus JVM start-up)
    claims/claim2_autoyara_preset/run.sh        ~30 s    (1-3 min on smaller machines)
    claims/claim3_augmented_preset/run.sh       ~35 s    (1-4 min on smaller machines)

    with -j 8:
    claims/claim4_incorrect_baselines/run.sh    ~10 s
    claims/claim5_bloom_filters_matter/run.sh   ~7 s
    claims/claim6_autopyara_vs_autoyara/run.sh  ~6 s
    claims/claim7_thresholds_and_k/run.sh       ~14 s
    claims/claim8_threat_hunting/run.sh         ~3 s
    claims/claim9_all_configurations/run.sh     ~11 s

    run_all_claims.sh -j 8                      ~2 min in total
    all 18 figures, one core (-j 1)             ~1.0 min

No claim is a long-running experiment; nothing needs to be scaled down.

--------------------------------------------------------------------------------
5. NETWORK ENDPOINTS CONTACTED
--------------------------------------------------------------------------------

install.sh reaches out to:

    pypi.org, files.pythonhosted.org   Python packages
    github.com                         Bloom filters, from the data-branch of
                                       https://github.com/Botacin-s-Lab/AutoPYaraPyPI
    zenodo.org                         the evaluation data

The claims run entirely offline once install.sh has completed.
