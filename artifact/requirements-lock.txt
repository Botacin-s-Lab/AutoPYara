# Pinned dependency versions for the AutoPYara ACSAC 2026 artifact.
#
# WHY THIS FILE EXISTS
#     autopyara's setup.py declares loose constraints (e.g. "scikit-learn>=1.0") so
#     that ordinary users get current releases. That is right for a published
#     package but wrong for an artifact: a reviewer installing months after
#     submission would resolve different versions than we verified against.
#
# HOW IT IS USED
#     install.sh installs exactly this file into ./.venv; the Dockerfile installs it
#     into the image. To install by hand:
#
#         python3.12 -m venv .venv && . .venv/bin/activate
#         pip install -r artifact/requirements-lock.txt
#
#     No python3.12 or venv module available? Use conda instead (install.sh does
#     this automatically, or force it with USE_CONDA=1):
#
#         conda create --prefix .venv python=3.12 pip && conda activate ./.venv
#         pip install -r artifact/requirements-lock.txt
#
# PYTHON VERSION
#     Python 3.11 or 3.12. scikit-learn 1.8.0 needs Python >= 3.11, and numpy 1.26.4
#     publishes no wheels for Python 3.13. All pins below ship Linux x86-64 wheels
#     for 3.11 and 3.12.
#
# VERIFIED ON
#     Ubuntu Linux x86-64, OpenJDK 17/21.
